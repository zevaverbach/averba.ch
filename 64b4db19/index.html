In Broad Daylight

How the game works right now: a three.js game built from 32 source modules (build.py inlines them into one HTML file), a countdown, and a clown.

The core loop

Survive until the clock runs out while a clown hunts you. Find the exit (yard) or the key and then the attic door (house). The sky darkens as time drains.

One frame

src/30_main_loop.js update(dt) runs this every frame while state === 'play':

update(dt)
  non-play states (dying, night, read, transition) get their own branch and return
  batUpdate, fpUpdate        # bat, kick, party horn, first-person arms
  timeLeft -= dt             # paused while the clown is in a stance
  buildFlow                  # pathfinding grid toward you      (27_pathfinding)
  updateClown                # chase, lunge, line of sight      (28_clown_ai)
  updateFriends              # more clowns arrive, giggle creeps (29_friends_ai)
  exit / pickup / note checks
  clock, setDay(timeLeft / DAY)   # sky darkens                  (19_day_cycle)

Levels are data

Everything that differs between levels lives in WORLDS (src/01_levels.js). Levels alternate.

yardeven levels
  • 1 floor, no key
  • 4 paper clues
  • exit at the far end
  • friends walk in over the fence
houseodd levels
  • 3 floors, stairs between them
  • key + attic door on the top floor
  • clown climbs the stairs 3.5 s after you arrive
  • friends come up the stairs

worldForLevel(n) = n % 2 === 1 ? house : yard. The bat and the horn (Q, stuns clowns) carry across levels.

Code layout

src/   (32 modules, each under 400 lines)
├── 00-02   setup, level data, collision
├── 03-11   yard scene: ground, fence/house, props, balloons, neighbourhood, papers
├── 12-16   clown: face/suit textures, parts, IK rig, poses
├── 17-19   audio, state/blood/toast, day cycle
├── 20      house scene (3 floors, windows)
├── 21      game flow: reset, begin, die, nightfall, moveToNextStage
├── 22-26   input, arms, party horn, bat + kick, render + HUD
├── 27-29   pathfinding, clown AI, friends AI
├── 30      main loop
└── 31      title screen + browser-saved profiles

Build and deploy

src/*.js→ build.py→ one HTML file→ node --check

Pushing to Forgejo main is the whole deploy:
